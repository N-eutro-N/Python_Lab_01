## Введение

Цель работы — изучить базовые типы данных и основные конструкции языка программирования Python (числа, строки, срезы, списки, кортежи, множества, словари), а также освоить современные инструменты разработки: инкапсуляцию логики в импортируемые модули и модульное тестирование с использованием фреймворка pytest.

1. `task_00_distance.py` — составить словарь словарей расстояний между городами по их координатам;

7. `task_06_songs_list.py` — вычислить суммарное время звучания песен из списка и словаря;

## Инкапсуляция и создание верхнеуровневого модуля

В исходных файлах заданий весь код расположен на верхнем уровне модуля, поэтому при импорте он выполняется целиком, вместе с выводом на консоль. Чтобы исключить побочные эффекты, логика каждого задания вынесена в отдельные функции, которые принимают данные через аргументы и возвращают результат без печати; исходные данные оформлены константами модуля, а вывод на консоль перенесён под конструкцию `if __name__ == "__main__"`. Такой модуль можно безопасно импортировать и одновременно запускать как сценарий.

Для корректного импорта модули переименованы: имена вида `00_distance.py` не являются допустимыми идентификаторами Python, поэтому обычная конструкция `import` с ними не работает. Файлы получили префикс `task_` (`task_00_distance.py`, …, `task_10_store.py`), что сохранило нумерацию заданий и сделало имена валидными. Модули объединены в пакет `solutions` с файлом `__init__.py`, поэтому импорт, например, выглядит так: `from solutions.task_05_zoo import final_zoo`.

Верхнеуровневый модуль `lab.py` выполняет все задания и собирает результаты. Функция `run_all()` возвращает словарь результатов всех заданий, функция `print_report()` печатает сводку в удобочитаемом виде; вызов `print_report(run_all())` выполняется только при прямом запуске модуля. Разделение вычислений и вывода позволяет переиспользовать результаты заданий в тестах и других программах. Структура проекта показана на рисунке 12, результат запуска `lab.py` — на рисунке 13.

## Автоматизированное тестирование

Функциональность работы покрыта автоматическими тестами с использованием фреймворка pytest (файл `test_lab.py`). Для каждого модуля заданий определён отдельный класс тестов: `TestDistance`, `TestCircle`, `TestOperations`, `TestMovies`, `TestFamily`, `TestZoo`, `TestSongs`, `TestSecret`, `TestGarden`, `TestShopping`, `TestStore`; верхнеуровневый модуль проверяется классом `TestLab`. Всего написано 35 тестов, все они проходят успешно.

Проверяются как точные значения вычислений (площадь круга, расшифрованная фраза, отчёт по складу), так и свойства результатов: симметричность матрицы расстояний, отсутствие мутации исходного списка зоопарка, соответствие вручную составленного словаря `SWEETS` программно рассчитанным двум минимальным ценам. Для сравнения чисел с плавающей точкой используется `pytest.approx`, исключающий ошибки прямого сравнения из-за двоичного представления дробей; вывод консоли фиксируется встроенным средством `capsys`. def distance(point_a, point_b):
```python
    (x_a, y_a), (x_b, y_b) = point_a, point_b
    return ((x_a - x_b) ** 2 + (y_a - y_b) ** 2) ** 0.5

def build_distances(sites):
    return {
        name_a: {
            name_b: distance(coord_a, coord_b)
            for name_b, coord_b in sites.items()
        }
        for name_a, coord_a in sites.items()
    }
```

```python
def two_cheapest(shops, product):
    offers = [
        {'shop': shop, 'price': item['price']}
        for shop, items in shops.items()
        for item in items
        if item['name'] == product
    ]
    return sorted(offers, key=lambda offer: offer['price'])[:2]
```

```python
def stock_report(goods, store):
    report = []
    for name, code in goods.items():
        quantity = sum(lot['quantity'] for lot in store[code])
        cost = sum(lot['quantity'] * lot['price'] for lot in store[code])
        report.append(f'{name} - {quantity} шт, стоимость {cost} руб')
    return report
```
